所持 は今持っている枚数、 次のLvに必要 はレベルを1つ上げるのに要る枚数で、 不足が無いものには「Lvアップ可能」を付けている。
レベルの下の → 13（+2） は、 今の所持枚数だけで続けて上げたときの到達レベル。 1レベル上げるごとに枚数を使い、残りで次も上げられるなら続ける、という数え方をしている。 ゴールドは考えていないため、実際にはゴールドが足りずそこまで上げられないことがある。
マスタリー はゲーム内の「カードタスク」の段階。 課題の内容と、段階の中でどこまで進んでいるかは公式APIから取得できないため、段階だけを示す。 数字は いまの段階 / いま解放されている上限 / そのカードの最大 の順に並べている（例: 7/7/10 は「解放ぶんは終えていて、 レベルを上げれば10まで伸ばせる」状態）。 タスクは3つで1セットになっていて、セットはカードレベル {{ mastery_unlock_levels | join(" / ") }} で順に解放される。 未解放のセットは、そのカードを使っても進まない。
マスタリーは、そのカードで3勝すると解放される。まだのカードは1つ目を「—」にしている。 セットの総数はカードによって違い、3セットあるカードは最終的に10、2セットなら7で打ち止めになる。 公式APIはどのカードも10と返し、解放の状況も返さないため、 上限はタスクセットの数から、解放はカードのレベルから求めている。
