# 公開の設定手順

分析結果をインターネット上に置き、PCがスリープしていてもスマートフォンから
見られるようにする手順。所要時間はおよそ15分。

---

## 0. 仕組み

サーバーは借りない。**あらかじめ計算し終えた画面をファイルとして書き出し、
無料のファイル置き場に上げるだけ**の構成にする。

```
[あなたのPC]
  1. 対戦を収集する
  2. 全画面をHTMLとして書き出す
  3. アップロードする
        |
        v
[Cloudflare Pages]  ← 無料。24時間つながる
        |
        v
[あなたと友人のスマートフォン]  ← いつでも見られる
```

表示される内容は**最後にアップロードした時点のもの**になる。PCを1日1回起動すれば
1日1回更新される。プログラムが動き続ける必要はないので、費用はかからない。

### URLについて

公開先は次の形になる。

```
https://<プロジェクト名>.pages.dev/<推測困難な32文字>/
```

後半の32文字はランダムに生成される。**このURLを知っている人だけが閲覧できる。**
検索エンジンにも載らないよう設定している。URLを知らせる相手は選ぶこと。

---

## 1. Cloudflareのアカウントを作る

1. https://dash.cloudflare.com/sign-up を開く
2. メールアドレスとパスワードを入力して登録する
3. **確認メールのリンクを必ず開く**

クレジットカードの登録は不要。ドメインの購入も不要。

> **手順3を飛ばすと、後のアップロードで失敗する。**
> メール未確認のままだと、ログインには成功するのにプロジェクト作成だけが
> 次のエラーで止まる。原因が分かりにくいので、先に済ませておくこと。
>
> ```
> Your user email must been verified [code: 8000077]
> ```
>
> メールが見当たらない場合は迷惑メールフォルダを確認する。
> それでも無ければ、https://dash.cloudflare.com にログインすると画面上部に
> 確認を促す帯が出るので、そこから再送できる。確認後、同じコマンドを
> 再実行すればよい（`wrangler login` のやり直しは不要）。

---

## 2. アップロード用ツールにログインする

コマンドプロンプトやPowerShellで、プロジェクトのフォルダに移動して次を実行する。

```bash
npx --yes wrangler@latest login
```

ブラウザが開くので、Cloudflareへのアクセスを許可する。**この操作は最初の1回だけ。**

> `npx` は Node.js に付属するコマンド。すでにインストール済みであることを確認済み。

---

## 3. 静的サイトを書き出す

```bash
python -m src.exporter.static_export
```

`dist/` フォルダの下に、推測困難な名前のフォルダが作られる。この名前が公開URLの
一部になる。**この名前は控えておく必要はない。** 後からいつでも確認できる。

---

## 4. 最初のアップロード

プロジェクト名を決めて実行する（英小文字・数字・ハイフンのみ）。

```bash
npx --yes wrangler@latest pages deploy dist --project-name cr-analyzer
```

初回はプロジェクトの作成確認が出るので、指示に従って進める。
完了すると `https://cr-analyzer.pages.dev` のようなURLが表示される。

**実際に開くURLは、この後ろに推測困難な文字列を付けたもの**になる。
次のコマンドで正確なURLを確認できる。

```bash
python -m src.exporter.publish --skip-collect --skip-upload
```

出力の最後に公開URLが表示される。

---

## 5. 自動化の設定

`config.yaml` を開き、`publish` の項目を書き換える。

```yaml
publish:
  enabled: true
  project_name: "cr-analyzer"
```

これで、収集から公開までを一括で実行できるようになる。

```bash
python -m src.exporter.publish
```

### 定期実行を公開込みに切り替える

これまでは収集だけを定期実行していた。公開まで行うよう登録し直す。

```bash
powershell -ExecutionPolicy Bypass -File scripts/register_task.ps1 -Publish
```

以降、収集のたびに自動でアップロードされる。

---

## 6. 友人へURLを渡す

確認したURLをそのまま伝える。友人側に必要な準備は何もない。
ブラウザで開くだけで、あなたと同じ画面が見られる。

Safariで開いて「ホーム画面に追加」すると、アプリのように起動できる。

---

## 運用について

### 更新のタイミング

アップロードは、あなたのPCで定期収集が動いたときに行われる。
PCがスリープ・電源オフの間は更新されないが、**閲覧はいつでもできる**。

### 通信量

1画面あたり300〜400KB程度。カード画像は表示サイズに合わせて縮小し、
WebP形式へ変換しているため、スマートフォンの通信でも負担にならない。

### 費用

Cloudflare Pages の無料枠に十分収まる。サイト全体で10MB以下、
1日のアップロード回数も無料枠（500回/月）を大きく下回る。

### URLを変えたいとき

URLが第三者に知られてしまった場合は、次のコマンドで新しいURLを発行できる。

```bash
python -m src.exporter.static_export --rotate-secret --clean
python -m src.exporter.publish --skip-collect
```

古いURLは、次回のアップロードで削除される。

---

## うまくいかないとき

| 症状 | 原因 | 対処 |
|---|---|---|
| `npx` が見つからない | Node.js が入っていない | https://nodejs.org からインストールする |
| ログイン画面が開かない | ブラウザの既定設定 | 表示されたURLを手動でブラウザに貼り付ける |
| `email must been verified` | メールアドレス未確認 | 確認メールのリンクを開いてから再実行する |
| `Project not found` | プロジェクト名の誤り | Cloudflareの管理画面で名前を確認する |
| 画面が古いまま | アップロードされていない | `data/logs/collect.log` を確認する |
| 404 が出る | URLの推測困難な部分が抜けている | `publish --skip-collect --skip-upload` でURLを確認する |
