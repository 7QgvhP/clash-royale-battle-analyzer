# APIトークン取得手順

クラッシュロワイヤル公式APIのトークンを発行し、本ツールから使えるようにするまでの手順。所要時間はおよそ10分。

---

## 0. この作業で何をするのか

やることは3つだけ。

1. Supercellの開発者サイトでアカウントを作る
2. **許可IPに `45.79.218.79` を指定して**トークンを発行する
3. トークンとプレイヤータグを `.env` に書く

**手順2の「許可IP」の指定がこの作業の要点**であり、ここを間違えると後で必ず動かなくなる。理由は次節のとおり。

---

## 1. なぜ `45.79.218.79` を登録するのか

Supercellのトークンは、**発行時に登録したIPアドレスからのアクセスしか受け付けない**。登録外のIPから叩くと `403` で拒否される。

自宅の回線はグローバルIPが変動しうる。ルーターの再起動や回線側の都合でIPが変わると、その瞬間からツールが全滅し、トークンを発行し直すまで復旧しない。

そこで本ツールは、RoyaleAPIが公開している中継サーバー `proxy.royaleapi.dev` を経由してAPIを呼ぶ。Supercell側から見たアクセス元は常にこの中継サーバーのIP `45.79.218.79` になるため、**自宅のIPが何回変わっても影響を受けない。**

```
[自宅PC]  --->  [proxy.royaleapi.dev]  --->  [Supercell API]
 IPは変動          IP: 45.79.218.79            ここに見えるIPは常に固定
```

したがって、トークンに登録すべきIPは**自分のIPではなく、中継サーバーのIP**である。ここを自分のIPにしてしまうと、プロキシ経由のアクセスが弾かれる。

---

## 2. 開発者アカウントを作る

1. ブラウザで **https://developer.clashroyale.com** を開く
2. 右上の **Login** から、アカウント作成の導線に進む（`Sign up` / `Create account` などの表記）
3. メールアドレスとパスワードを入力して登録する

> ゲーム内のSupercell IDとは**別のアカウント**である。ゲームのログイン情報は使えないため、新規に作成する必要がある。

4. 登録したメールアドレス宛に確認メールが届くので、本文中のリンクを開いて認証を完了する

   届かない場合は迷惑メールフォルダを確認する。

5. 認証後、あらためてログインする

---

## 3. トークンを発行する

1. ログイン後、画面上部の **My Account** を開く
2. **Create New Key**（新しいキーを作成）を選ぶ
3. 次の3項目を入力する

   | 項目 | 入力する内容 |
   |---|---|
   | **Key Name** | `battle-analyzer`（半角英数字。任意の名前でよい） |
   | **Description** | `Personal battle log analyzer`（任意の説明） |
   | **Allowed IP Addresses** | **`45.79.218.79`** |

   **Allowed IP Addresses には必ず `45.79.218.79` を入力する。** 自分のIPアドレスではない。画面に自分のIPが初期値として表示されている場合は、消して入力し直す。

4. **Create Key** を押す
5. 発行されたトークンが画面に表示される

トークンは `eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...` のように始まる、**数百文字の非常に長い文字列**である。

6. トークン全体を選択してコピーする

   途中で切れていないか注意する。長いため、選択漏れが起きやすい。

> 発行済みトークンは My Account からいつでも再表示できる。控え忘れても作り直す必要はない。

---

## 4. プレイヤータグを調べる

1. クラッシュロワイヤルを起動する
2. 左上の自分の名前をタップしてプロフィール画面を開く
3. 名前の下に表示されている `#` で始まる文字列がプレイヤータグ

### タグを書き写すときの注意

クラロワのタグに使われる文字は、以下に限られる。

```
0 2 8 9 P Y L Q G R J C U V
```

**アルファベットの `O`（オー）は使われない。`0`（ゼロ）である。** 同様に `I`（アイ）や `1` も使われない。読み間違えると `404` エラーになるので、迷ったらゼロと解釈する。

---

## 5. `.env` に設定する

プロジェクト直下の `.env.example` を `.env` という名前でコピーし、次のように記入する。

```
CR_API_TOKEN=eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...
CR_PLAYER_TAG=#ABC12345
CR_USE_PROXY=true
```

### 記入時の注意

- **トークンは改行を入れず1行で書く。** エディタの折り返し表示は問題ないが、実際に改行を入れてはいけない
- トークンをクォートで囲む必要はない
- `=` の前後に空白を入れない
- プレイヤータグは `#` を付けたまま書く（URLエンコードはツール側で行う）
- ファイルは **UTF-8** で保存する

---

## 6. 動作確認

### ツールの診断コマンドを使う場合

```bash
python scripts/doctor.py
```

トークンの有効性、プレイヤータグの存在、プロキシ経由の疎通をまとめて確認する。

### コマンドで直接確認する場合

PowerShellで次を実行する。`ここにトークン` と `ABC12345` は自分の値に置き換える。

```bash
$t = "ここにトークン"; Invoke-RestMethod -Uri "https://proxy.royaleapi.dev/v1/players/%23ABC12345" -Headers @{Authorization="Bearer $t"} | Select-Object name, tag, trophies
```

自分の名前・タグ・トロフィー数が表示されれば成功。

---

## 7. うまくいかないとき

| 症状 | 原因 | 対処 |
|---|---|---|
| `403` / `accessDenied.invalidIp` | 許可IPの指定が誤っている。自分のIPを登録してしまった場合が最も多い | My Account でキーを削除し、`45.79.218.79` を指定して作り直す |
| `403` / `accessDenied` | トークンが誤っている。コピー時に末尾が欠けている場合が多い | トークンを再表示し、全体をコピーし直す |
| `404` / `notFound` | プレイヤータグが誤っている | `O` と `0` の取り違えを疑う。ゲーム内の表示と1文字ずつ照合する |
| `503` | Supercell側のメンテナンス中 | 時間をおいて再試行する。ゲーム自体も遊べない状態のはず |
| 何も返らない・タイムアウト | プロキシへの通信が遮断されている | ファイアウォールやVPNの設定を確認する |

### 直接アクセスに切り替えたい場合

プロキシを使わず、自分のIPを登録して直接叩くこともできる。

1. https://api.ipify.org で自分のグローバルIPを確認する
2. そのIPを許可IPに指定してキーを作り直す
3. `.env` の `CR_USE_PROXY` を `false` にする

ただしIPが変わるたびにキーの作り直しが必要になるため、常用は推奨しない。

---

## 8. トークンの取り扱い

トークンは**パスワードと同等の秘密情報**として扱う。

- `.env` は `.gitignore` に登録済みであり、Gitには含まれない
- スクリーンショットや画面共有にトークンが写り込まないよう注意する
- 質問などで設定内容を他人に見せる際は、トークン部分を必ず伏せる
- 漏洩が疑われる場合は、My Account から該当キーを削除して作り直す。削除すれば古いトークンは即座に無効になる

なお、このトークンで可能なのは**公開情報の読み取りのみ**である。ゲームアカウントの操作や課金は一切できない。とはいえ不必要に共有しないこと。
