# 0003. 対戦履歴を定期的に収集し、ローカルの SQLite に蓄積する

- ステータス: Accepted
- 日付: 2026-09-05（v1.0.0）

## 背景（Context）

公式 API の `battlelog` は、直近の数十戦分（30件ほど、約5日分）しか返さない。それより古い対戦は永久に取得できない。

## 決定内容（Decision）

定期的に API から対戦履歴を取得し、差分をローカルの SQLite（`data/battles.db`）に UPSERT して蓄積する。定期実行は Windows のタスクスケジューラで行う。

## 理由と検討した代替案（Consequences / Alternatives）

- 過去の履歴は遡れないため、蓄積する方式が必須になる。分析の対象は、運用を始めた日以降の対戦だけになる。
- 収集の間隔が空きすぎると、その間の対戦を取りこぼす。
- 収集の間隔は、標準では毎日23時に1回とする。対戦数が多い日は取りこぼしうるため、間隔指定（既定は60分おき）での登録も選べる。
