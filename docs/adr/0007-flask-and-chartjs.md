# 0007. Python ＋ Flask ＋ Chart.js のローカル Web ダッシュボードにする

- ステータス: Accepted
- 日付: 2026-09-05（v1.0.0）

## 背景（Context）

蓄積したデータを、グラフや表で見る画面が必要。

## 決定内容（Decision）

Python ＋ Flask ＋ Chart.js で、ローカルの Web ダッシュボードを作る。静的サイトの書き出しも、同じテンプレートを描画して作る（そのため、ダッシュボードを起動しない運用でも、Flask アプリのコードは削除できない）。

## 理由と検討した代替案（Consequences / Alternatives）

- 収集と閲覧を分離し、ダッシュボードは見たいときだけ起動する。
