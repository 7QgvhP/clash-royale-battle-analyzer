# 0005. 自デッキを類似度でグループ化する

- ステータス: Accepted
- 日付: 2026-09-05（旧要件定義書の作成日）

## 背景（Context）

同じデッキでも、1〜2枚を入れ替えて使うことが多く、完全一致で区別すると、デッキごとの試合数が分散する。

## 決定内容（Decision）

8枚中6枚以上（`deck_grouping.similarity_threshold`）が一致するデッキを、同じグループとみなす。使用回数の多い順に代表を決め、集計のたびに全デッキをまとめて再計算する。

## 理由と検討した代替案（Consequences / Alternatives）

- 毎回まとめて再計算するのは、逐次的に行うと処理の順序に結果が依存するため（旧要件定義書 8.4 より）。
