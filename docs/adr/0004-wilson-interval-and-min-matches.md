# 0004. 勝率に Wilson 信頼区間を付け、試合数の少ないものをグレー表示する

- ステータス: Accepted
- 日付: 2026-09-05（旧要件定義書の作成日）

## 背景（Context）

単純な `wins / n` は、試合数が少ないときに極端な値になる。

## 決定内容（Decision）

- すべての勝率に、Wilson score interval（95%、z = 1.96）による区間を付ける（例: `勝率 38.1% (±9.2%, n=42)`）。
- 試合数が最低試合数（既定 20）未満のものは、数値をグレー表示して「参考値」のバッジを付ける。行は隠さない。

## 理由と検討した代替案（Consequences / Alternatives）

- 試合数の少ない勝率を、過大に信じないようにできる。
- 行を隠さないことで、データが貯まっていく過程が見える。
